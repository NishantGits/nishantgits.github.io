**FlowMovies** is a streaming companion app in the Flow Ecosystem, available at [movies.flowchats.org](https://movies.flowchats.org).

## Overview

FlowMovies lets you browse and stream movies and TV shows directly from your Flow account, styled to match FlowChat's branding.

## Features

### Streaming
- **Automatic Fallback Providers**: Movies and shows are sourced with redundant providers, so playback stays reliable even if one source goes down.
- **Browse & Search**: Find titles across movies and TV shows from a unified catalogue.

### Single Sign-On
- **One Account**: FlowMovies uses the same account as FlowChat — if you're logged in there, you're logged in here.
- **Shared JWT Authentication**: SSO is powered by shared session tokens across `.flowchats.org` subdomains, with no separate login step.

### Unified Design
- **Themed to Match FlowChat**: FlowMovies shares the same visual language as the rest of the Flow Ecosystem — not a bolted-on third-party player.
- **Dashboard Widget**: Trending titles surface on the FlowChat home screen so you can jump in without leaving your workspace.

## Get Started

Visit [movies.flowchats.org](https://movies.flowchats.org) — if you already have a FlowChat account, you're in.
