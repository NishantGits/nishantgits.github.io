**FlowWeather** brings live weather data directly into your FlowChat workspace.

## Overview

FlowWeather gives you current conditions and forecasts without leaving your workspace. 

## Features

### Live Conditions
- **Real-Time Data**: Current weather conditions updated continuously — no API key required to configure.
- **Powered by Open-Meteo**: Uses the Open-Meteo open-source weather API for accurate, global coverage.

### Global Weather Access
- **Any Location**: Search for weather conditions anywhere in the world by city, region, or coordinates.
- **Forecasts**: View upcoming conditions alongside current readings.
