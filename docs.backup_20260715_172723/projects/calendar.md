Calendar is a built-in scheduling feature that gives every user a personal calendar. Create events, set recurring schedules, and share calendars with teammates — all without leaving FlowChat.

## Features

### Views & Navigation
- **Multiple Views**: Switch between month, week, and day views to see your schedule at the right level of detail.
- **Agentic Management**: AI models can search, create, update, and delete events on your behalf autonomously.
- **Automation Overlay**: Active automations and past runs surface as virtual calendar events for full visibility.

### Sharing & Collaboration
- **Calendar Sharing**: Share any calendar with individual users or groups via access grants.
- **RSVP & Attendees**: Invite users to events with pending, accepted, declined, and tentative status tracking.
- **Color Coding**: Customize colors per calendar and per event to visually separate your workstreams.

### Event Details
- **Location & Description**: Attach locations and rich text descriptions to any event.
- **Reminders**: Set per-event alerts delivered via toast notification, browser notification, or webhook.

## Use Cases

| Scenario | FlowChat Calendar Makes it Easy |
|-----------|--------------------------------|
| **Schedule Team Meetings** | Generate agendas with AI-assisted planning |
| **Manage Deadlines** | Track project milestones with customizable reminders |
| **Coordinate Client Calls** | Plan meetings across different time zones |
| **Convert Insights into Tasks** | Transform chat-based ideas into actionable to-do items |
