**FlowCall** brings real-time voice and video calling directly into your FlowChat workspace.

## Overview

FlowCall is a built-in call overlay that launches from within any FlowChat conversation, letting you switch between text and voice without leaving your workspace. It is accessible via the standalone [interface](https://call.flowchats.org) or from within the chat interface.

## Features

### Voice & `1qz Video Overlay
- **In-Chat Calls**: Start a voice or video call directly from any chat session without navigating away.
- **Overlay Layout**: The call sits on top of your conversation so you can read and reference the chat while you talk.

### No Authentication
- **One Login**: FlowCall does not require logins — no unnecessary struggle.
- **Instant Join**: No struggle - the call session starts immediately.

### Instant Access
- **One-Click Launch**: Start a call from within any chat with a single click.
- **Direct URL**: Open a call session directly via the standalone [interface](https://call.flowchats.org).
